Localisation des fichiers exportés

Pour Windows :

  • Ouvrez l'Explorateur de fichiers (Win+E)
  • Allez dans "Ce PC" → "Téléchargements"
  • Ou tapez directement : C:\Users\[VotreNom]\Downloads\

Pour Mac :

  • Ouvrez le Finder
  • Dans la barre latérale, cliquez sur "Téléchargements"
  • Ou allez dans : /Users/[VotreNom]/Downloads/

Raccourcis utiles :

  • Ctrl+J : Ouvrir les téléchargements (Chrome/Edge)
  • Ctrl+T puis chrome://downloads
  • Ctrl+Shift+Y : Historique des téléchargements (Firefox)
Astuce : Vous pouvez modifier le dossier de destination dans les paramètres de votre navigateur.

Instructions d'utilisation

Onglet Canaux :

  • Cochez les canaux à afficher simultanément dans le domaine temporel et fréquentiel
  • Renommez les canaux dans la colonne "Nom" pour une identification plus claire
  • Choisissez une couleur pour chaque canal en cliquant sur le bouton de couleur
  • Positionnez les échelles Y : L (Gauche), R (Droite), ou aucune (Masquée)
  • Définissez min/max manuellement ou laissez vide pour l'échelle automatique
  • Activez la FFT pour afficher le spectre fréquentiel du canal
  • Utilisez les presets pour appliquer rapidement les mêmes valeurs Y à plusieurs canaux

Onglet Paramètres :

  • Ajustez l'épaisseur de trait pour toutes les courbes (temporel et FFT)
  • Configurez le pas d'échantillonnage (ms) du fichier
  • Consultez les informations du fichier (Fs, Points, Incrément)

Onglet Instructions :

  • Consultez cette aide à tout moment
